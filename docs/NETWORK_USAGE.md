# Haloscope 网络流量修复（2026-09-05）

## 问题

用户提供的诊断截图记录：Haloscope Preview 反复启动 Codex 0.146.0，触发插件目录下载；45 秒观察中对应子进程下载 16.25 MB。截图中历史请求数量来自用户的另一次调查，本次没有重新读取或重算这些历史日志。

源码中，请求 15 秒超时会安排 250 毫秒后的连接恢复；子进程退出会安排 1 秒后的重连。每次连接又可尝试启动 5 次。握手成功会结束该次尝试计数，随后的读取再次超时则能进入下一轮。原启动参数未关闭插件功能，停止操作也未确认旧进程退出。

## 修复行为

- 对 Haloscope 启动的每个监控/连接测试子进程使用 `--disable plugins --disable remote_plugin --disable apps --disable workspace_dependencies`。这些开关已用本机 0.146.0 的 `features list` 核实为 false，不写入用户的全局配置。
- 超时提高到 45 秒。初始化、传输失败和异常退出均暂停监控并显示手动重连提示，保留上次数据。打开面板和刷新已有错误状态不会重新启动进程。
- 只有启动应用、显式重连和原本正常监控的睡眠恢复会创建连接。处于错误状态的监控不会因为睡眠/唤醒重新启用。
- 停止时关闭 stdin、发出终止信号并异步等待；必要时只强制结束自己持有的子进程。若仍无法确认退出，保留占用状态，阻止新子进程覆盖。避免在 Swift 并发线程上调用可能卡住的 `waitUntilExit()`。
- 通过会话标识丢弃已取消连接的响应；新连接先等待前一次清理。退出应用也等待监控子进程清理。
- 任务查询间隔固定 60 秒；额度 30 秒；用量历史按尝试时间缓存 3600 秒。通知合并现有额度字段，不触发一轮额外查询。

## 验证

`swift test --disable-sandbox`：57 个测试全部通过，其中新增 8 个覆盖额度超时、初始化超时、启动失败、意外退出、通知突发、显式重连、初始化中取消，以及忽略终止信号的子进程清理。模拟服务完全在本地运行，不调用真实 Codex。

一次使用相同启动参数的受控真实子进程验证持续 45.1 秒：初始化、额度、用量历史、任务列表均成功；只启动一个子进程，无插件目录同步日志。nettop 按 PID 及观察到的后代进程累计，取得 23 条有效采样行：下载 **344,082 字节（约 0.34 MB）**，上传 **10,581 字节**。没有套用“没有采样行就是零流量”的假设。

该流量验证在后续刷新频率调整之前完成，未重测最终 30/60/3600 秒配置。此次短时观察中的下载量相对于用户截图约减少 98%；两次样本不是完全一致的实验条件，也不代表长期流量保证。它验证了监控功能在关闭插件相关功能后仍可使用，并未进行数小时的 GUI 持续运行。原始脱敏摘要见 [JSON 记录](probe/haloscope-network-fix-2026-09-05.json)。

本机同时构建了包含 arm64 与 x86_64 的 Preview 应用，交付前进行 ad-hoc 签名及严格验证。本地安装包需要手动安装；源码推送不包含 GitHub Release 安装包发布。

## 仅在任务执行时刷新

后续增加本地活动门控：额度/任务列表/用量历史保留 30/60/3600 秒间隔，但只在检测到实际执行中的本地任务时发送请求。无活跃任务时，启动后的初始化握手仍可完成，三类数据查询全部暂停；恢复活动沿用同一个监控子进程。

活动来源是 macOS 的进程及打开文件描述符信息，以及同一用户的 Codex 进程持有的可写 `sessions/.../rollout-*.jsonl` 文件。只识别 `event_msg.payload.type` 中的 `task_started`、`task_complete`、`turn_aborted` 和 `shutdown`。后台执行不依赖窗口焦点；任务计划、普通聊天消息和已关闭的历史日志均不作为活跃信号。不会读取或改写自动化计划、Codex 私有数据库、全局配置，也不保存或上传对话正文。首次读取后只处理新增日志字节。

该本地日志格式以本机 Codex 0.146.0 为验证对象，不是跨版本保证的公开活动 API。没有可读活动信号时暂停查询；远端主机上独立执行、未映射到本机可写会话日志的任务不在此检测范围。

验证：63 个测试通过。新增测试覆盖未执行的每周计划、开始/完成/中断、后台运行且日志暂时无变化、多个任务、日志部分写入和截断，以及空闲→运行→空闲→再次运行全过程中请求暂停/恢复且子进程启动次数保持 1。实际本机探针检查到 4 个正在打开的可写会话日志，并识别到执行中的任务；没有输出日志路径或正文。
